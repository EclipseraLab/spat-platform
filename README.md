# SPAT Platform

SPAT is a Web3 participation platform focused on daily engagement, crypto quizzes, missions, community activities, and points. This repository is separate from Onchain_Society.

## Product principles

- Users can sign up and participate without connecting a wallet.
- SPAT Points (SP) and Game Points (GP) remain separate until weekly game conversion.
- Reward claims are validated server-side and recorded in an auditable ledger.
- A future token or airdrop is a possibility, not a guarantee.

## MVP scope

- Landing page and account registration/login
- Member dashboard and profile
- Daily check-in and streaks
- Five-question weekly crypto quiz, shuffled per user
- Daily missions and social tasks with admin review
- Community events and weekly league
- SP points ledger and reward history
- Admin review tools and audit trail

## Later phase

- SPAT Blocks (Tetris-style game)
- SPAT Bounce
- SPAT Strike
- Weekly GP-to-SP conversion at 1,000 GP = 1 SP, with a shared 10,000 GP weekly cap per user and GP remainder carry-forward

## Status

Initial repository setup. Production authentication, database integration, reward logic, and deployment are not yet complete.
